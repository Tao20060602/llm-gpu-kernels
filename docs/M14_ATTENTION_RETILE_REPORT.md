# M14：query 分块与流水线调整仍有边界回归

六种配置的数值检查全部通过；训练选出的中间query长度规则，在独立边界输入中出现约16.5%最坏回归。因此不推荐启用此规则。保留冻结策略和所有回归结果，attention推荐路径仍为官方FA2。

## 方法与冻结

固定六种token32/64、G1/2、warps4/8、stages1/2组合，key64。使用现有M9四段直读内核，不改变数学算法。seed9109，T48/80/192 × selected511/3073；sink64/recent512/currentT。每配置另做T65/history33/17/41及T0检查。强对照每次复用buffer pack+未修改FA2公开算子。独立chunk64 FP32参考、原0.008误差界、API/Graph前后数值与输入hash。

训练Graph四轮AB/BA/BA/AB，每轮8样本、每样本2 replay、每图8 forward。每个配置必须全部六个输入正确；分桶两个输入geomean ratio≤.95、worst≤1.05才长复测（16样本、4 replay），失败则FA2且不尝试次优。small32–64、medium65–128、large129–256；总history≤4096、sink64/recent512/currentT，其余FA2。

## 判断

64行query分块和更多warps没有带来可靠收益。单阶段流水线在T80训练有效，T127/128长历史回归说明粗分桶不能替代跨query/历史边界验证。当前数据不足以归因硬件原因。下一轮先研究状态和mask简化，而不是继续根据已知赢家缩小域。

GPU resident热重复、单GPU SM86 BF16 forward；无model/RoPE/H2D/router/NanoKV/serving。M14策略保留实验用途，推荐默认FA2。M10冻结实验策略也含自定义路径且有回归，并非FA2回退策略。
