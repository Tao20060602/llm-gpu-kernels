# M11：split-KV 的完整成本与全域回退

8种split配置的边界检查和48候选行数值通过，但没有单一配置满足整个T≤256训练矩阵的收益/回归门槛。最终冻结为强FA2回退，不能把某个训练输入的局部赢家写成可部署策略。

## 实现与契约

四段KV按逻辑block拆成互不重叠区间。一张CTA计算query tile、G4 query heads和一个partition，输出FP32 partial(m,l,acc)；第二kernel用共同最大值稳定重标定、累加、归一化后写BF16。空partition或全部future-masked的有效行写l0/acc0/m=-inf，merge忽略；T0两个kernel都不启动。与M9相同BF16 Q[T,32,128]、KV[L,8,128]、历史全可见/current因果，无cat/repeatKV。

完整计时包括两次启动、partial scratch读写和merge；splits1也保留merge。每plan独立拥有input references、output和FP32 partial buffers，固定shape/address，当前stream按序启动，无CPU counts/readback或热路径分配。

scratch bytes=splits×T×32×130×4，输出另外T×32×128×2。在T65边界输入，scratch为1,081,600到8,652,800 bytes，不能因取消KV pack就称整体显存为零。

## 预先固定的选择方法

候选token_tile16/32 × splits1/2/4/8，G4/warps8/key64/stages2，共8。先T65/history33/17/41和T0，全部通过。seed3109，T48/112/224 × selected383/1793，sink64/recent512/currentT，共6输入；故意包含非整齐segment边界。强baseline每次pack到复用buffer后调用未修改FA2。

独立chunk64 FP32 oracle，TF32关闭；所有候选API/Graph前后检查、input hash、resources和scratch均保留。Graph paired四轮AB/BA/BA/AB、8样本、2replay、8forward/replay；选择一个全域配置，要求全部6正确、geomean ratio≤.95且worst≤1.05。没有合格者直接fallback，不进行无意义长复测。阈值和候选未事后修改。

## 判断

本实验拒绝单一全域配置。更高split数带来parallelism、scratch、merge与额外工作之间的权衡，具体原因仍缺少硬件计数器；不由CTA数量直接推断occupancy，也不将局部收益写成NanoKV/model/serving加速。

后续另立窄域T≤64实验：固定M11中有依据的token16/splits2，用新T24/56输入训练与长复测，再冻结后测新seed和更多边界T。大T保持成熟FA2回退。该新假设来自已知训练数据，需明确披露，不能回改本轮policy。
